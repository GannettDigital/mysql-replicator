# Security Policy

## Reporting Security Issues

The `mysql-replicator` team takes security vulnerabilities seriously. We appreciate your efforts to responsibly disclose your findings.

If you believe you have discovered a vulnerability or security issue:

1. **Do not create a public GitHub issue.**
2. Send an email to **dms-dba@gannett.com** with details about the issue.
3. Include relevant reproduction steps, environment details, and affected versions.

We will review reports promptly and coordinate remediation before public disclosure.
