# First beta — 0.1.0-beta.1

MySQL binary-log replication for the tested MySQL 8.4 InnoDB → MySQL 5.7 MyISAM
configuration. This is a prerelease for evaluation, with no stable compatibility
promise for future 0.x releases.

- Ordered capture, decoding and batched apply, with durable SQLite progress and
  relay/write-intent records; download buffering and detailed stage timing.
- INSERT/UPDATE/DELETE including multi-row execution, composite primary keys and
  the [qualified column types](https://github.com/GannettDigital/mysql-replicator/blob/v0.1.0-beta.1/PLAN/FLEET_COMPATIBILITY.md).
- Expanded [DDL support](https://github.com/GannettDigital/mysql-replicator/blob/v0.1.0-beta.1/PLAN/DDL_COMPATIBILITY.md), routines, partitions,
  multi-table rename and audited trigger skipping. Target triggers are rejected;
  events are rejected by default policy. Unsupported DDL stops replication.
- Source reconnect/binlog rotation handling, safe target reconnect and clean drain.
  Uncertain writes remain blocked for operator investigation.
- Commented YAML configuration, literal or environment passwords, strict default
  collation checking and explicit, audited opt-in collation translation.
- Linux x86_64 static archive and Debian package, checksums and dependency notices.
  Unit/integration Swift coverage and Periphery checks for contributors.

## Limits and migration

Other MySQL version/engine combinations are not yet accepted. Initial snapshot
copying remains external. MyISAM is nontransactional: a committed client operation
is not a crash-atomic write, and interrupted processes can require target repair.
No automatic recovery from uncertain writes is provided. Collation translation
preserves encoding bytes but can change comparisons and uniqueness.

Configuration is YAML only. Existing development users must cleanly stop and back
up state before upgrading, adjust the dedicated service account's permissions, and
resume without `--initialize`; see [installation and migration](https://github.com/GannettDigital/mysql-replicator/blob/v0.1.0-beta.1/docs/INSTALL.md).
Configuration version 2, SQLite schema version 8 and codec ABI are independent of
the application version. macOS binaries and Linux arm64 assets are not included.
