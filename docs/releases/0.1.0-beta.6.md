# Sixth beta — 0.1.0-beta.6

Release candidate. Full release checks have not run on this candidate. Update
this status after the final PR and main checks pass.

This release extends MySQL value and DDL support. It adds source GTID
preservation and operational controls. The four replication profiles remain:

| Source | Target |
| --- | --- |
| MySQL 8.4 | MySQL 5.7 MyISAM |
| MySQL 5.7 | MySQL 8.4 InnoDB |
| MySQL 5.7 | MySQL 5.7 MyISAM |
| MySQL 5.7 | MySQL 5.7 InnoDB |

## Values, schemas and DDL

- Preserve supported native character encodings, identifier bytes and SQL text.
- Support fixed-scale floating-point columns, numeric display attributes,
  ENUM/SET metadata, exact defaults and zero-width columns.
- Add an explicit compatibility option for JSON YEAR values sent to MySQL 8.4.
  JSON defaults and expression indexes follow target version and engine rules.
- Extend FULLTEXT, generated expressions, CHECK compatibility, table options,
  partitions, stored objects, renames and compound ALTER operations.
- Apply executable version comments according to the target's native version
  rules. Keep the comments in the SQL sent to the target.
- Support unique-key and full-row identity when a primary key is absent.
  Extend InnoDB foreign-key handling and preserve records needed for recovery.

See [support status](https://github.com/GannettDigital/mysql-replicator/blob/v0.1.0-beta.6/docs/SUPPORT.md) and [JSON limits](https://github.com/GannettDigital/mysql-replicator/blob/v0.1.0-beta.6/docs/JSON_SUPPORT.md).
A missing test is not the same as an unsupported feature. These additions do not
mean that every MySQL statement or cross-version combination has been tested.

## GTIDs and operations

- Track tagged GTIDs in capture, replay, checkpoints and duplicate checks.
- Preserve source GTIDs on the target by default. The target account needs
  additional privileges. MySQL 5.7 cannot preserve tagged GTIDs.
- Set `target.preserveSourceGTIDs: false` when target assignment is unavailable,
  including under the documented Cloud SQL customer permissions. SQLite still
  retains the complete source GTID. See [GTID settings](https://github.com/GannettDigital/mysql-replicator/blob/v0.1.0-beta.6/docs/GTID_PRESERVATION.md).
- Add wildcard include filters with native MySQL precedence. Save filter settings
  in the state directory and reject changed filters on resume.
- Use the same TLS policies for source and target, including `verifyCA`.
- Save operation and byte totals with checkpoints. Estimate replay time from
  remaining GTIDs and recent processing rate. Poll live source progress on a
  separate connection. Replay does not connect to the source.
- Override YAML options from the CLI. Include selected binlog byte ranges and
  original error positions in support bundles.

See [status and estimates](https://github.com/GannettDigital/mysql-replicator/blob/v0.1.0-beta.6/docs/OPERATIONS.md), [command options](https://github.com/GannettDigital/mysql-replicator/blob/v0.1.0-beta.6/docs/COMMAND_LINE.md),
and [offline replay](https://github.com/GannettDigital/mysql-replicator/blob/v0.1.0-beta.6/docs/OFFLINE_REPLAY.md).

## Install and upgrade

Downloads include a static Linux x86_64 archive, a Debian amd64 package and a
saved Linux/amd64 container image. Use the installer with
`--version 0.1.0-beta.6` to select this release. No macOS or ARM64 binary is provided.

Stop the old process cleanly. Back up the configuration and full state directory.
State format 13 records GTID mode and table filters. Older state requires explicit
`target.preserveSourceGTIDs: false` to upgrade. Use the original filters. Enabling
GTID preservation or adding include filters to older state requires a new verified
baseline. Older binaries cannot open format 13; retain the backup for rollback.
The codec ABI is 14. Build Swift and Rust components from the same revision.

Target commits and SQLite checkpoints remain separate. MyISAM writes are not
atomic. A target GTID alone does not prove that all writes succeeded. Uncertain
writes still need DBA review. This release does not add automatic crash repair.

FULL row images and CRC32 remain required. XA, transaction compression and some
opaque JSON values remain outside the implemented support. Target version,
engine and GTID restrictions still apply. Read [the support guide](https://github.com/GannettDigital/mysql-replicator/blob/v0.1.0-beta.6/docs/SUPPORT.md)
before changing a production replication path.

## Tests and build

MySQLSyntax has its own build target and unit tests. CI adds a parallel Swift
format check. The final release PR runs the full catalog on all four profiles.
The release workflow copies the exact packages tested by successful main CI.
Local unit and selected container results are recorded in the
[beta.6 additions plan](https://github.com/GannettDigital/mysql-replicator/blob/v0.1.0-beta.6/PLAN/Beta.6.additions.md). Full release results and
performance checks remain pending.
